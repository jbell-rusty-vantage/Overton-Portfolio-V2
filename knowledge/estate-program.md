# Travellers Rest content program

The edition-two house program binds the companion, scene tiers, narration, objects, viewing folio and project placements. It is validated before release. The portfolio collection remains independent; estate overrides can move a book inside this house without changing its collection identity.

The accepted portico and 3.19 metre ceiling remain unchanged. Surveyed structure, interpreted furniture and reconstructed upper landing have different evidence quality. Both scene tiers must satisfy anchors-v2. Never run a broad seed over owner changes. Use the read-only importer plan, immutable media verification, and audited scoped apply for an authorized edition.
