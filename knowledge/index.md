## Concepts

- [Application boundaries](system-overview.md) — The homepage is the 2D portfolio; /library is the optional Travellers Rest visit. Reports, résumé, soccer, blog, favorites and the text catalog remain independent HTML destinations. The office lives under /admin. The seven-room hall is retired. The current Travellers Rest world uses native Three.js; earlier Travellers Rest prototype tools are preserved at the owner’s explicit request. React owns accessible controls and reading surfaces. [reference; Architecture Concept]
- [Legacy URLs and current destinations](route-compatibility.md) — Old view=world links translate to the current visit. Entrance maps to /library, stacks to #cabinet, computer-station to #screen/main; periodicals, favorites-wing, evolution-hall and reading-room map to /blog, /favorites, /evolution and /catalog. Unknown zones fall back to the entrance. [reference; Architecture Concept]
- [Authorization and public projections](security-and-privacy.md) — Every admin page, action and handler must authorize through requireAdmin/getAdmin. The proxy is an optimistic cookie redirect, not authorization. Cache Components requires a Suspense boundary around request, cookie and database reads; console exports use officePage even when the parent layout is mounted. [reference; Architecture Concept]
- [Collection identity and publication](collection-publication.md) — types.ts defines Volume, Leaf and Block without renderer dependencies. taxonomy.ts preserves existing category and shelf slugs; owner-edited shelf titles and slot order come from PostgreSQL. Hall node names and camera geometry no longer determine collection eligibility. collection-query.ts owns request-local cached rows; catalog.ts owns projection and policy application. [reference; Architecture Concept]
- [Reports and shared reading surfaces](report-authoring.md) — One projected Volume feeds the portfolio report and native book. Authored blocks are validated and sanitized before projection; templates resolve deterministic leaf keys and order. Report sections, neighboring projects, figures, focus and Escape belong to the shared report, not a second world-specific implementation. [reference; Architecture Concept]
- [Authenticated authoring and drafts](admin-and-drafts.md) — The library action is a thin authenticated adapter. library-use-cases owns validated book, page, placement, shelf-title and estate-release commands. The adapter acquires the advisory transaction lock and runs a Serializable transaction; snapshots, audits and signals receive the same transaction client. Conflicts preserve submitted input and require reload. [reference; Architecture Concept]
- [Drift-checked content promotion](content-promotion.md) — Code deployment, content publication and media delivery are separate operations. release-content plans against a specific target and retains a private baseline. Apply only the reviewed scoped plan; it compares owner fields and refuses drift. Never regenerate a baseline to bypass a refusal. The six-study publication and its prior receipts are the starting edition, not permission for broad seeding. [reference; Architecture Concept]
- [Database migrations and schema contract](database-contract.md) — Prisma schema.prisma is authoritative: 53 models, including PortraitLedger, and four existing migration directories at cleanup baseline. Import the generated client and types through lib/db. New models and columns need triple-slash documentation and snake_case database mappings. Applied SQL migrations are immutable; add another migration. Functions, views and triggers also have readable definitions in prisma/sql/objects.sql. [reference; Architecture Concept]
- [Database and deployment environments](integrations-and-environments.md) — Production and Preview have isolated database targets. The Vercel project is overton-portfolio-v2; the Git remote is jbell-rusty-vantage/Overton-Portfolio-V2. Inspect the bound project and target fingerprint before operations. DATABASE_URL and DATABASE_URL_UNPOOLED must describe the same database; migrations use the direct connection. [reference; Architecture Concept]
- [Local office, samples and development](local-development.md) — Use Node 24 and npm ci. npm run admin:local opens the real local content office on 127.0.0.1:3078; its saves use the configured database and actor local-office. Account changes still require a real session. npm run preview:library uses port 3077 and a scoped review projection; preview visibility is not publication. [reference; Architecture Concept]
- [Travellers Rest content program](estate-program.md) — The edition-two house program binds the companion, scene tiers, narration, objects, viewing folio and project placements. It is validated before release. The portfolio collection remains independent; estate overrides can move a book inside this house without changing its collection identity. [reference; Architecture Concept]
- [Renderer sessions and resource lifecycle](world-runtime.md) — Engine is the native Three.js facade; React owns navigation and accessible controls. ResourceOwner tracks geometries, textures and materials, including resources that arrive after cancellation. Scene readiness includes assets, shader preparation and native paper surfaces. A failed or lost WebGL context falls back to plain reading. [reference; Architecture Concept]
- [Visit history and saved reading places](navigation-and-bookmarks.md) — The location hash describes place, held object, report section, leaf and page. lib/estate/world parses and formats it; visitor-navigation validates portrait destinations. session.ts owns browser subscriptions and the stable overton-estate: storage namespace. Preserve tw-route and existing bookmark keys. [reference; Architecture Concept]
- [Native paper and HTML page measurements](book-rendering.md) — sheets.ts defines page metrics shared by printed HTML and geometry; paginate.ts partitions content into native surfaces. Reader.tsx owns accessible page content and controls. Volume3D, BookHold and turn geometry own physical handling. These boundaries keep paper size and printed text synchronized. [reference; Architecture Concept]
- [Viewing folio and soccer collection](folio-and-media.md) — The period-paper viewing folio exposes project recordings and all nine soccer clips. Playback, fullscreen and keyboard ownership must remain usable on desktop and phone layouts. Screen fragments select the current folio; retired computer-screen database records no longer drive portfolio reads. [reference; Architecture Concept]
- [Archive evidence, attribution and rights](historical-evidence.md) — Letters, scans and historical cards identify their source records and distinguish transcription from interpretation. The HABS TN-14 survey, archival letters, maps and printed reports remain under their asset roots with credits and reproducible derivative preparation. Preserve source URLs and uncertain readings; never turn an imagined portrait reflection into archival quotation. [reference; Architecture Concept]
- [Immutable media and delivery inventory](asset-pipeline.md) — Replacement images and GLBs receive new content-addressed filenames; never overwrite immutable bytes. Verify SHA-256 after upload, not only file size. Blob references and bundled files have distinct withdrawal paths. Removing a UI or hiding content does not revoke public URLs or cached copies. [reference; Architecture Concept]
- [Artwork and scene authoring tools](authoring-tools.md) — Runtime builds consume checked-in derivatives and imported manifests. Blender, Python and FFmpeg are authoring dependencies, not browser dependencies. pack-kit validates named nodes, pivots, dimensions and both tiers; pack-estate validates house anchors. Keep source masters and provenance with the corresponding asset root. [reference; Architecture Concept]
- [Grounded portrait text and spending](portrait-text.md) — The imagined Judge uses approved project evidence and cited navigation tools; public privacy checks also constrain retrieval. Live text uses the configured gateway with durable PortraitLedger reservations and a cap of $0.05 per turn, $1 per day and $5 per month. The reviewed fallback uses authored excerpts when the provider fails. [reference; Architecture Concept]
- [Voice policy and authored narration](portrait-voice.md) — Live two-way voice remains disabled until provider/server hard spending and session termination bounds are verified. A browser socket and a nominal three-minute timer are not a proven hard backstop. Available credentials do not authorize enabling it. [reference; Architecture Concept]
- [Qualification and performance evidence](testing-and-performance.md) — Portable checks cover types, lint, domain/privacy contracts, migration/upload safety, disposable admin editing, accessibility and no-JavaScript reading. Native world gestures, book pages and GPU lifecycle require workstation qualification; software-renderer CI is not equivalent. [reference; Architecture Concept]
- [Deployment, rollback and withdrawal](release-and-recovery.md) — Run typecheck, lint, unit and safety tests, inventory, production build, disposable authoring and browser qualification before release. Verify a protected Preview with its isolated database, then deploy the reviewed source to Production and verify actual public URLs. Record source SHA, deployment ID, rollback target, tests and limitations in a new release receipt. [reference; Architecture Concept]
- [Searchable OKF documentation](documentation-system.md) — The registered flat knowledge bundle uses OKF 0.2 Markdown with parsed YAML. The pinned local agent-docs v1.2 snapshot generates compact guides, a source/test map and an index. Bootstrap hashes identify the canonical local snapshot; no nonexistent upstream commit is claimed. [reference; Architecture Concept]
- [Future worlds and immersive VR](future-worlds.md) — Travellers Rest is the only implemented world. Immersive VR, WebXR sessions, stereoscopic rendering, controller/hand input, headset comfort and spatial audio are proposed requirements, not supported features. ## Search

Run from the repository root (PowerShell or bash):

```text
node .agent-docs/cli.mjs search --repo . --query "retry cancellation"
node .agent-docs/cli.mjs search --repo . --query "admission" --format json
rg -n -i -C 2 "admission|deterministic" knowledge -g "*.md"
```

The executable searches registered concepts only, using current files. It ranks title, description, tags, headings, and body matches; returns paths and line snippets; accepts --type, --tag and --limit. It is lexical search, not embeddings. No match exits 1; invalid input exits 2. Try a domain term from the routes or rg when wording differs.
