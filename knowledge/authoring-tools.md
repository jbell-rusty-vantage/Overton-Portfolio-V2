# Artwork and scene authoring tools

Runtime builds consume checked-in derivatives and imported manifests. Blender, Python and FFmpeg are authoring dependencies, not browser dependencies. pack-kit validates named nodes, pivots, dimensions and both tiers; pack-estate validates house anchors. Keep source masters and provenance with the corresponding asset root.

The old hall packer is a historical text artifact, not a supported npm command. Do not rerun one-off seeds against their old targets. Read the estate program and immutable-media rules before changing manifests. The world-lab fixture remains useful for current renderer inspection; the standalone Travellers Rest prototype remains preserved at the owner’s request.
