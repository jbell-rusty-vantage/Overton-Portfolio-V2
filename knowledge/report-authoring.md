# Reports and shared reading surfaces

One projected Volume feeds the portfolio report and native book. Authored blocks are validated and sanitized before projection; templates resolve deterministic leaf keys and order. Report sections, neighboring projects, figures, focus and Escape belong to the shared report, not a second world-specific implementation.

Use the local office to edit books and pages; preserve the version token for stale-edit refusal. A detailed figure can provide a separate detail image and accessible caption. Reports offer full-size playback when physical pages are small. Do not substitute new copy or redesign for a cleanup. Verify return from a report to the exact marked leaf and page.
