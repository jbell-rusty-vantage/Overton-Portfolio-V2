# Grounded portrait text and spending

The imagined Judge uses approved project evidence and cited navigation tools; public privacy checks also constrain retrieval. Live text uses the configured gateway with durable PortraitLedger reservations and a cap of $0.05 per turn, $1 per day and $5 per month. The reviewed fallback uses authored excerpts when the provider fails.

Do not expose hidden projects through citations, tool results or aliases. Built-in web search supports history and current AI, not personal research on the owner. Qualification includes bounded live quality, concurrency, failure and withdrawal; unit tests alone do not establish live-provider behavior. Preserve budget and provider security boundaries during cleanup.
