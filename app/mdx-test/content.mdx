# Welcome to MDX Test Page

This is a **demo page** written in _MDX format_ that showcases various markdown elements styled with our custom components.

## What is MDX?

MDX allows you to write **JSX** directly in your markdown files. This enables you to create dynamic and interactive content while maintaining the simplicity of markdown.

### Features Demonstrated

Here are some features you can use in MDX:

1. **Styled headings** - Custom styled with Tailwind CSS
2. **Formatted text** - Bold, italic, and other text formatting
3. **Lists** - Both ordered and unordered lists
4. **Code blocks** - Syntax highlighted code examples
5. **Links** - [Visit Next.js docs](https://nextjs.org/docs)

### Code Example

Here's a simple JavaScript function:

```javascript
function greet(name) {
  return `Hello, ${name}! Welcome to MDX.`;
}

console.log(greet("Developer"));
```
