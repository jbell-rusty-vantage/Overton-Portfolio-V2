## Step 1: Set Up Your Accounts and Tools

### 1. Create a Vercel Account

Head to [vercel.com/signup](https://vercel.com/signup) and create your account. Once logged in, you'll see your dashboard where you can create new projects.

![Vercel Dashboard](/blogimages/vercel-dashboard.png)

You have two options:

- **Let Vercel create a new GitHub repository** with a pre-built Next.js template
- **Connect an existing GitHub repository**

For this tutorial, we'll let Vercel create the repository for us.

### 2. Install Node.js

Download Node.js from [nodejs.org](https://nodejs.org/en/download). Choose the recommended version and follow the installation instructions for your operating system.

![Node.js Download Page](/blogimages/node-download.png)

<CodeWindow title="Verify Installation">
```bash
# Check if Node.js is installed
node --version

# Check if npm is installed

npm --version

````
</CodeWindow>

### 3. Create Your Next.js Project

In your Vercel dashboard:
1. Click "Add New Project"
2. Select "Create a new repository"
3. Choose the Next.js template
4. Name your repository (e.g., "my-portfolio")
5. Click "Create"

Vercel will create a GitHub repository and deploy your initial Next.js app automatically!

## Step 2: Clone and Set Up Locally

Now you need to clone the repository Vercel created and set up local development.

<CodeWindow title="Clone Your Repository">
```bash
# Clone the repository Vercel created
git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git

# Navigate to the project directory
cd YOUR_REPO

# Install dependencies
npm install

# Start the development server
npm run dev
````

</CodeWindow>

Your local development server will start at `http://localhost:3000`.

## Step 3: GitHub Authentication

After cloning, you need to authenticate with GitHub to push changes back to your repository. Here are three reliable methods:

### Option 1: GitHub CLI (Recommended for Beginners)

<CodeWindow title="GitHub CLI Setup">
  ```bash # Install GitHub CLI from https://cli.github.com # Then authenticate:
  gh auth login ```
</CodeWindow>

Follow the prompts:

- Choose `GitHub.com`
- Choose `HTTPS`
- Authenticate via browser

After this setup, Git pushes will work automatically.

### Option 2: Personal Access Token

1. Generate a token at [github.com/settings/tokens](https://github.com/settings/tokens)
2. Choose scopes: `repo` and `workflow`
3. When you push, Git will prompt for credentials:

<CodeWindow title="Push with Token">
  ```bash git push origin main # Username: your-github-username # Password:
  [paste your token here] ```
</CodeWindow>

### Option 3: SSH Key Authentication

<CodeWindow title="SSH Setup">
```bash
# Generate SSH key
ssh-keygen -t ed25519 -C "your-email@example.com"

# Add to SSH agent

eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519

# Copy public key

cat ~/.ssh/id_ed25519.pub

````
</CodeWindow>

1. Copy the output and add it to GitHub → Settings → SSH Keys
2. Change your remote URL to SSH:

<CodeWindow title="Switch to SSH">
```bash
git remote set-url origin git@github.com:YOUR_USERNAME/YOUR_REPO.git
```
</CodeWindow>

## Step 4: Development Workflow

Now you have a complete development workflow:

1. **Make changes locally** in your code editor
2. **Test locally** with `npm run dev`
3. **Commit and push** to GitHub
4. **Vercel automatically deploys** your changes

<CodeWindow title="Typical Workflow">
```bash
# Make your changes, then:
git add .
git commit -m "Add hero section to homepage"
git push origin main

# Vercel will automatically build and deploy!
```
</CodeWindow>

**Don't worry about build errors!** They happen to everyone. Check the error in Vercel's dashboard, fix it locally, and push again.

## Troubleshooting Common Issues

### Build Errors

If your deployment fails:

1. Check the error message in Vercel's dashboard
2. Test your build locally: `npm run build`
3. Fix the issue and push again

### Environment Variables

For API keys and secrets:

1. Add them in Vercel dashboard → Settings → Environment Variables
2. Use them in your code: `process.env.YOUR_VARIABLE`

### Domain Setup

To use a custom domain:

1. Go to your project in Vercel
2. Settings → Domains
3. Add your domain and follow DNS instructions
